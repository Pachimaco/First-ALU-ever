# ALU
## Hay que hacer el vidio
## Objetivo
Diseñar e implementar en el simulador Logisim el ALU (Unidad Aritmética Lógica).

## Descripción del Circuito
El circuito procesa las siguientes señales:
### Entrada de datos:
- 8 bits (N)
- 8 bits (R0)
- 8 bits (R1)
- 4 bits (banderas)
- 5 bits (Instrucciones)

### Salidas:
- 8 bits (ACC)
- 8 bits (ACC2)
- 4 bits (Banderas)

## Detalles
  1. Para cada bloque de instrucción haz un bus de datos de entrada de 28 bits para que pongas todas tus entradas.
  2. Para cada bloque instrucción haz un bus de datos de salida de 20 bits para que pongas todas tus salidas.
